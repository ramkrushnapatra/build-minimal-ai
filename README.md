# build-minimal-ai

A minimal document Q&A app powered by Retrieval-Augmented Generation (RAG).

Upload documents, ask questions, and get answers grounded in your content with source citations.

## Stack

- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: FastAPI (Python)
- **Vector store**: ChromaDB
- **LLM**: OpenAI API
